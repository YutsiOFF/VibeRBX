Un jeu Roblox.

VibeRBX est un studio de création de jeux Roblox où plusieurs agents IA travaillent ensemble : ils codent en Luau, modélisent dans Blender et branchent tout sur Roblox Studio.

Pas un chatbot. Un vrai studio.

Les agents ne se contentent pas de générer du code à copier : ils utilisent de vrais logiciels grâce au protocole MCP.

◆

Agents en parallèle

Plusieurs agents sur le même projet, chacun avec sa conversation, son modèle, son rôle et ses outils. Les sessions sont conservées.

▲

Blender → Roblox

Les agents modélisent dans Blender, sauvegardent le .blend, exportent un FBX prêt pour Roblox et le publient après ta validation. « Rends la lame plus longue » rouvre le même fichier.

●

Roblox Studio branché

Serveur MCP officiel de Studio : lecture du jeu, exécution Luau, playtest et console accessibles aux agents.

Installer en trois étapes

Télécharge

Clique sur « Télécharger » : l’installateur de la dernière version se télécharge directement. Lance-le.

Autorise

L'installateur n'est pas encore signé : Windows peut afficher « Éditeur inconnu ». Clique sur « Informations complémentaires » puis « Exécuter quand même ».

Connecte

Dans Agents IA → Fournisseurs, installe et connecte ton agent. Ajoute Blender MCP et Roblox Studio MCP dans Outils MCP.

Recommandé : Git, Blender 3.0+, uv (winget install astral-sh.uv), Roblox Studio et Rojo.
